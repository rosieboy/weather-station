# Documentation screenshots / Skärmbilder för dokumentationen

Captured / Tagna: **2026-10-10**, 1280 × 720. Most images use the live Pi
dashboard at `http://vaderstation.local:3000/?kiosk=1`. Weather day/hourly images
were refreshed from the local development preview using the same live HA data
to show the restored pressure and three-hour trend. The UI is Swedish; captions are provided
in both main README versions. Each filename describes the use case, not a permanent
state. No image editing, synthetic values or device-control commands were used.
Sonos grouping selection was cancelled. The browser theme was returned to Auto.

Most images show actual reported state after the 03:00 scheduled backup.
Temperature history was temporarily unavailable in those captures; `24 h —` is
the normal fallback. The refreshed weather images include available history.
A manual Day theme does not change the landscape’s actual nighttime appearance.
Device-health events show recovery after backup; car health/mileage were already
older than one day. The calendar image uses the previously discussed two-day
Sitevisiondagarna event, without unrelated personal calendar entries.

## Updating / Uppdatering

Capture from the current dashboard at 1280 × 720 through its UI, inspect every
image, and update the capture date and matching Swedish/English captions.
Keep relevant controls and surrounding context visible. Do not trigger lighting,
playback or grouping just to stage a screenshot. Keep credentials and unrelated
private calendar content out of screenshots.

Older images at `static/weather.png`, `static/rooms.png`, `static/sound.png` and
`static/visualisering.png` remain historical assets. The main README illustrations

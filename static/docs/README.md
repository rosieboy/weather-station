Captured / Tagna: **2026-10-10**, 1280 × 720, live Pi dashboard at
`http://vaderstation.local:3000/?kiosk=1`. The UI is Swedish; captions are provided
in both main README versions. Each filename describes the use case, not a permanent
state. No image editing, synthetic values or device-control commands were used.
Sonos grouping selection was cancelled. The browser theme was returned to Auto.

Images show actual reported state after the 03:00 scheduled backup. Temperature
history was temporarily unavailable at capture; `24 h —` is the normal fallback.

Device-health events show recovery after backup; car health/mileage were already
older than one day. The calendar image uses the previously discussed two-day
Sitevisiondagarna event, without unrelated personal calendar entries.
